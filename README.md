# react-Capstone
This is a mock website for a restaurant called Little Lemon.
The Little Lemon web app is designed to allow users to:

Learn about the restaurant and its story
Explore the menu (coming soon)
Make online table bookings
Place online orders (coming soon)
Log in to access personalized features (coming soon)
This project demonstrates front-end development best practices, component reusability, and clean UI/UX design.

# How to run
In the Terminal in the little-lemon folder type `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page will reload when you make changes.\
You may also see any lint errors in the console.
